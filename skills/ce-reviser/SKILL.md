# 修经验

错的经验在写下时查不出来:写经验的人把一次的结论推广成了通则,换更强的模型核对、拿相似的旧题对照,都很少能发现。
它只在**注入了、结果失败、而且看得出怎样才对**的时候暴露。你的事就是拿这些失败去修那条记忆。

CE 的自进化实验里,这样修过、再压到 150 字以内的规则效果最好(同一批题:不注入 42.3、原规则 49.7、修过并压短 53.7)。
写长了反而不好:分支一多,模型会选错分支。

## 每次运行

1. `list_surprises(days=7, min_expected=0, limit=200)`,按 `memory_id` 归拢。先处理失败次数多的,一次最多 10 条记忆。
2. 每条记忆 `get_memory`:看正文、`version`、出处(`evidence` 里 `source` 那段对话)和效果。`status` 是 rejected 的跳过。
3. 读失败的对话:每次失败带的 `conversation_ids` 取第一个,`get_conversation` 读(长的用 `offset` 接着读),一条记忆最多读 3 段。
   在原文里找到注入标记 `⟦CE:SEEN …⟧`(含这条记忆的 id),看之后发生了什么:
   - 智能体照着这条记忆做了什么;
   - 结果哪里不对;
   - **怎样才对**:用户的纠正、后来找到的可行做法、测试结果。
   看不出怎样才对的那段不算数,只在报告里记一句。
4. 逐段判断失败和这条记忆的关系,三选一:
   - **记忆写错了**:是哪句话让智能体做错?最常见的是把只对某种情形成立的做法写成了通则,或者漏了区分条件。
   - **用错了场合**:这次问的是另一件事,本不该用这条记忆。
   - **不是记忆的问题**:智能体没照它做,或者失败另有原因。
5. 改写(只在至少有一段「记忆写错了」或「用错了场合」时):
   - 记忆写错了:改正那句,或加上能把这次失败和原来情形区分开的条件;出处那段对话里仍然成立的部分保留。
   - 用错了场合:不改做法,把触发条件写窄,写清适用于哪种情况。
   - 只有一段失败时,**不要从它推出新的通则**,只加能区分它的条件——从一次推广,正是原来写错的原因。
   - `then` 不超过 150 字:第一句写适用情境;分情况写成「若……则……;若……则……」,每种情况只写判断用的线索和做法;
     不写机理、例子、本次对话的文件名、id 和具体数字(除非它们本身就是要记的事实)。`because` 不超过 30 字。
6. 写回:
   - `update_memory(memory_id, then=..., because=..., expected_version=<get_memory 的 version>,
     reason="修经验:<依据哪几段失败、改了哪句>", actor="ce-reviser")`。报 409 就重读、按新版本再改一次。
   - 每段判为「记忆写错了」或「用错了场合」的失败对话:
     `add_evidence(memory_id, conversation_id, kind="contradicted", quote=<原文一两句>, actor="ce-reviser")`,
     `quote` 原样摘自 `get_conversation`,摘能看出「怎样才对」的那句。
7. 在本工单里写报告(见末尾模板)。

## 跳过哪些失败

- 评测和实验:批量出题或判分格式的对话(开头是 `You are grading a final answer`、`Solve the problem.` 这类),
  或者只有一问一答、没有人参与。
- 知识平台自己的对话(项目是 `ce-platform`)。
- 对话已过保留期(`get_conversation` 报 404)。

## 不要做

- 不新建记忆,不驳回、不删除,不改 `status`、`confidence`、`group`(置信度由 CE 按效果自己调,状态和分组归人或维护流程)。
- 不批量改;一条记忆一次 `update_memory`。
- 失败原因看不清、看不出怎样才对的,不改。
- 不把对话原文、密钥、令牌贴进工单或记忆。

## 报告模板

```
看了:意外 N 次,涉及记忆 M 条,读了 K 段对话(跳过 评测 a、看不清 b、过期 c)
改了 p 条:
- <memory id 前 8 位>:<写错了 | 用错场合>,依据 <几段失败>;<改了哪句,一句话>
  前:<原 then 前 40 字>
  后:<新 then 前 40 字>
没改的:
- <memory id 前 8 位>:<不是记忆的问题 | 看不出怎样才对>,<一句话>
```
