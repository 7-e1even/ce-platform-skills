# 《天才是怎样思考的》:五条法则与技法

整理自安迪·阿莱尼柯夫《天才是怎样思考的》,按智能体能照着做的步骤改写,没有摘录原文。

作者的主张:天才不是天生的、不一定出少年、不是超人也不是疯子,「偶然发现」其实是有准备的钻研者迟早会碰上的——
没准备的人把异常当成故障。天才是做出显著的新东西、有益于他人、并且被广泛接受的人;这种能力可以训练。

全书五条法则:①拒绝放弃 ②为什么一不顺就说「不」③一带百万 ④重视他人(开放)⑤进入天才轨道(加速创新本身)。

格式:是什么 / 什么时候用 / 怎么做 / 容易错在哪。

---

## 法则一:拒绝放弃

**比要求多做**
- 要 5 个就给 6、7、9 个;天才是超出要求和期望去做的人。数量第一,质量其次:先放开量,再回头挑质量。
- 错:追加的只是换说法。

**找到一个解后再找第二个**
- 做出一个就翻页,是放弃的另一种形式。

**为失败负责**
- 失败时不说「老师没教」「题出得蠢」「时间不够」,说「是我这边的问题,我去补上缺的那块」。
  一次只改一个错误,不要把「什么都是我的错」变成陷阱。
- 对智能体:复盘时把原因落到自己可控的动作上;把「时间不够、条件不够」换成「怎样才能做到」。

**不偷看答案**
- 熬到自己想通(「啊哈」)才有训练效果;直接看答案只是知道了,不是会了。

## 法则二:为什么一不顺就说「不」

**「为什么不」**
- 自己或别人说出「不可能」「没人做过」「我们这儿不这样」「不现实」时,改问「为什么不?」,再去找满足条件的实例。
  例:「圆的正方形」——说不可能的是脑子,不是世界;卷起来的方手帕、旋转的方块、圆形的城市广场都是。
- 例外:法律、道德、行为规范,不对它们问「为什么不」。
- 错:当成「永远不收敛」。

**个人的自由思考**
- 头脑风暴时不许批评别人,那对自己也该一样。想到就记,把每个念头当成跳向下一个的台阶。
- 一边想一边否决 = 油门刹车交替,颠簸却走不远。

**正面表达**
- 不同意、提约束时,用正面的话表达同样的意思(说「这样会伤着你」,而不是「别跳」)。
- 对智能体:把经验和规则写成「该怎么做、为什么」,少写「禁止……」。

**联想三级**
- 转移:在同一类里换(圆的黄的酸的 → 柠檬、橙子);转接:换到相邻一类;跳跃:一下跨过好几类(幽默和好故事都靠它)。
- 给自己的候选标级;全是转移,说明还没想开。
- 错:为跳而跳。

**形态矩阵(BAMMA)**
- 什么时候:要系统地铺开方案空间时。
- 怎么做:把对象拆成至少十个部件或维度 → 每个部件**单独**想至少十种取值,包括怪的 → 每个部件加一栏「0」(这个部件不存在)
  → 任意组合、不丢要素,给怪组合找用途 → 查新颖度,挑最好的。卡住就用随意取词填格子。
  作者偏好从一个对象往外「炸开」的发散式矩阵,而不是先定好范畴再往里收。
- 先拿和工作无关的东西练几次,工作上的思路太根深蒂固。
- 错:维度拆错全盘皆错;组合数大不等于好方案多,一定要筛。

**理想最终结果(「0」那一栏)**
- 问:「完全没有这个装置、这一步,功能怎样仍能实现?」技术系统都在朝这个方向演进(书写从刻石头一路到语音输入)。
- 用来定方向,不是直接可落地的方案。

**综观全局(高斯求和)**
- 动手逐项处理之前,先看整体结构:有没有配对、对称、能不能用乘法代替逐个相加。
- 错:按出现顺序一项项算(大脑默认走阻力最小的顺序路径,2+2×2 就是这么错的)。

## 法则三:一带百万

**找本质:下定义**
- 先用反例逐条拿掉不必要的特征(桌子:材料?几条腿?水平?都不是必须的)。
- 在抽象阶梯上找最近的上一级(家具),一下排除不相干的东西(墙、地板);再和同级的兄弟比(椅子、书架、床、台灯),
  用「为了……」说出功能区别;压到两三个词。
- 检查「必要且充分」:少一点会和兄弟分不开,多一点就混进了表象。好的解常在抽象阶梯的上端。
- 错:停在表面特征;上位类取得太高。

**找本质:删除式检验**
- 对每个因素问「没有它,这件事还会发生吗?」会 → 不是本质。(教学:没有校长、校舍、考卷照样能教,没有学生就不行。)
- 再问「这份工作的核心目的是什么?」——眼前堆满的杂务常常不是核心。

**反例法**
- 能举出一个反例推翻定义,是需要专门练的能力(柏拉图「没毛的两足动物」被一只拔了毛的鸡驳倒)。
- 对每个特征问:有没有不具备它的 X?有没有具备它却不是 X 的?

**根本性的新**
- 新东西会生出新东西(轮子 → 车 → 发动机)。在几个候选里,优先选能引出最多后续变化的那个。
- 发现比发明更根本:一个发现会引出成千个发明。

**打破常规五步**
- 什么时候:看似无解,或条件互相矛盾(四个点三条线回到起点、两条相交的平行线、一条线穿过四个点)。
- 怎么做:①相信有解 ②记住解在既成秩序之外 ③**把既成秩序写成定义**(线是什么?平行是什么?是哪种几何?)——
  定义既是工具也是围墙,用它找出包含它的更大秩序 ④跳过去(线可以有宽度;不是所有面都是平的)⑤写出新解。
- 错:只喊「跳出框框」,却说不出默认的是哪一条。

**远离要求五步**
- 逐层问「为什么不能越过」:框 → 纸 → 已知的形态 → 文化里的定式 → 一切已知事物。
- 先弄清验收标准:知道怎样算好,第二次的产出明显不同(画外星动物,先凭经验画,再看评分标准画)。
- 错:连真正的硬约束也越过了。

**多余信息**
- 题面塞了大量无关信息,把注意力引开(「卡车司机多大」——数字全是干扰,第一句就是答案)。
- 怎么做:先只读第一句和问句;逐条问「这和问的有关吗」;理解在前,计算在后;找出被默认的前提
  (方格必须一样大吗?「其中一个不是」指的是哪一个?)。
- 世上的难题大约几十种类型,认得类型就快。

**新的质量,逐级核对**
- 别分「主观新 / 客观新」,而是逐级比:个人、家庭、单位、城市或国家、世界。跨过的界限越多,新的质量越高。
- 要调查、比较,像专利审查那样对照已有的一切。作者自己重新「发现」过导师早写过的东西——自觉新不算数;
  尴尬了也别放弃,方向对了就继续。

**提出问题**
- 提出问题和解决问题一样是创造。把做过的题改出新变体,训练表述问题的能力。

**五个层面**
- 任何新东西都要经过:存在 → 交流(说给别人)→ 工具(变成别人能用的方法)→ 方向(用来解决别人的问题)
  → 创新(被广泛接受)。低层能跳到高层,高层也会滑落。用法:写下自己的长处在每一层的下一步。
- 作者自己承认这个分法不严格,当清单用。

## 法则四:重视他人(开放)

- 作者认为这是最重要的一条:听取他人的观点、需要、情感,甚至错误;把他人当作同等价值的人。
- **创造性交流 vs 破坏性交流**:前者让人愿意继续交流(倾听、接纳信息、鼓励想法),后者打断、否定、攻击。
  「好的东西都是脆弱的」:好的结果是几个因素同时成立,错一个就坏;破坏容易,建设难。
- **听副语言**:音量、音高、语速、口音比字面先被感知。练习:在嘈杂处听最远的人说话;把音量调到勉强能听见。
  文字里的副语言:回复长短、标点、重复、改口、语气。
- **找共同点**让对话继续;少说「不/没有」,多加肯定的话。
- **船上会议**:最年轻、职位最低的先发言,依次往上,推迟权威和批评。缺点:想法受人数和等级限制。
- **畅所欲言的两阶段**:第一阶段不批评,全部记下;第二阶段另一组人审可行性,或原组筛选改进。
  改进版:讨论中每冒出一个新特征,就分出一个小组专门深挖(分支式)。

## 法则五:进入天才轨道(加速创新本身)

- 「创造」= 让某个过程更快、更好;衡量创造的价值就看快了多少、好了多少。
- 最高一层是在创新这件事上创新:让产生和推广新东西的过程本身变快。
  例:把公司的点子会压缩到 48 小时——第一天产出约两千个点子,连夜聚成约两百组,第二天精炼成十几个完整的「主意包」。
- **对待方法的方式**:领会实质、掌握要领、加以改进、付诸应用。书里每介绍一种方法,作者都给了自己的改进版;
  已知方法解决不了,就发明新方法。
- 被拒绝时用五条法则复盘:不放弃(换个地方)、质疑那个「不」、找更大的受众、重视他人、想办法加速。

## 语言类技法(都属于法则二、三的工具)

- **随意取词**:取一个随机词 → 列出它的特征 → 逐个连到要改进的对象上,**不许换词**。每个词通常带出两三个主意;
  手边备十几二十个随机词。只适合开放问题,不适合唯一解的问题。
- **焦点客体**:先让大家列名词、再给每个名词配形容词,最后才亮出要改进的对象,把形容词套上去;
  只用每次想到的第四个形容词(前三个太常见)。
- **亲身拟物**:「我是 X……」讲它的故事,从它的「愿望」里找改进点。
- **符号模拟**:操作名称而不是对象(名字和东西的关系是随意的,可以「非科学地」拆词玩)。
- **幻想模拟**:给对象加魔法属性,或和别的东西互换功能;它和理想最终结果是一回事。
- **一览表**:预置问题清单逐条过;它其实是随意取词的一种,可以升级成填空式的模板。
- **书名法**:用两个不协调的词给对象起个书名(短暂的长久、不洁的干净)。
- **符号学模型**:换一种符号系统表达同一内容(文字 → 图、表格、诗、歌)。
- **动态法**:只改一个可测参数、其余不变,看什么时候质变(梳齿越来越少,依次变成耙、叉、牙签)。用来找本质和边界。
- **拟人法**:问这个东西怎么呼吸、进食、繁殖。
- **隐喻法**:物质名词 + 想象名词(「希望的光」),适合写作、广告、教学,不适合技术。
- **四步推迟**:第一个念头先不执行,沿同一方向再推四步(画点:中心 → 靠边 → 圆周上 → 圆外 → 纸的背面,仍在要求之内)。

## 不照搬的部分

- 「一分钟一百万个主意」是形态矩阵的组合数,不是一百万个好主意。
- 开篇的性格小测作者自己说不科学。
- 鼓劲口号、对「保守的人」的嘲讽、各种「×100 万」,是修辞,不是方法。
