# 发散与收敛的技法

整理自《天才是怎样思考的》,按智能体能照着做的步骤改写。书的模型:先发散(拼数量、不踩刹车、从近联想走到远联想),
再收敛(穿过表象抓必要且充分的特征);好的解常在题面默认的秩序之外。书里重生成、轻检验,检验要另外补上
(见 SKILL.md 第 5 步)。

格式:是什么 / 什么时候用 / 怎么做 / 容易错在哪。

## 发散

**拒绝放弃**
- 要 N 个就给 N 个以上。够数后强制再加几个,并问「为什么停在这里」。
- 错:追加的只是同义改写。

**「为什么不」**
- 生成阶段脑中冒出「不可能」「没人这样做」时,改成「为什么不?」,再去找满足条件的实例。
- 错:用在法律、伦理、安全约束上;或者从不收敛。

**联想三级**
- 给每个候选标级:转移(同类里换)、转接(相邻类)、跳跃(跨好几类)。全是转移就继续。
- 错:为跳而跳,成了噱头。

**形态矩阵(含「没有」一栏)**
- 什么时候:要系统地覆盖方案空间时。
- 怎么做:拆出部件或维度 → 每个维度单独写多个取值(包括怪的)→ 每个维度加一栏「没有」→ 任意组合,给怪组合找用途 → 再筛。
- 错:维度拆错,全盘皆错;组合数多不等于好方案多,一定要筛。

**理想结果(「没有」那一栏)**
- 问:「完全没有这个东西 / 这一步,目的怎样仍能达到?」用来定改进方向。
- 错:把它当成可以直接落地的方案。

**四步推迟**
- 第一个想法先不执行,沿同一方向再推四次;每一步问「这太常见了吗?题目真的禁止这样吗?」
- 错:机械地凑步数。

**远离题面的暗示**
- 答案被题面暗示时,逐层问「为什么不能越过」:框 → 载体 → 已知形态 → 惯例 → 已知事物。
- 错:连硬约束也越过了。

**打破常规五步**
- 什么时候:看似无解,或条件互相矛盾。
- 怎么做:相信有解 → 解在默认秩序之外 → 写出默认的秩序是什么,找包含它的更大秩序 → 跳过去 → 写出新解。
- 错:只喊「跳出框框」,却说不出被默认的那一条是什么。

**换视角 + 「还有别的吗」**
- 给每次换视角起一对对立范畴(上/下、远/近、前景/背景、用户/系统),再找还没用过的那一对。
- 错:只换了解读,没落到行动。

**随意取词**
- 取一个随机词 → 列出它的特征 → 逐个映射到问题上,不许换词。
- 错:用在只有唯一解的问题上(书里明说不适合)。

**其他小技法**
- 拟人:问这个东西怎么「吃」、怎么「长」、怎么「繁殖」。
- 以「我是 X」讲它的故事。
- 用两个矛盾的词概括对象。
- 换表征:文字 → 表格、流程、时间线。
- 预置问题清单,逐条过。
- 让最不资深的视角先说,推迟权威意见。

## 收敛

**找本质**
- 在抽象阶梯上找最近的上位类 → 和同级的兄弟找区别 → 用「为了……」写出功能 → 压到两三个词。
- 错:停在表面特征;上位类取得太高,成了空话。

**动态法**
- 只改一个可测的参数,其余固定,逐级增减,看何时发生质变;那一点就是边界。
- 错:一次改好几个参数,看不出因果。

**先看全局**
- 动手前先看整体结构:有没有配对、对称,能不能用乘法代替逐项相加。
- 错:按出现顺序逐项处理。

**剔除多余信息**
- 信息多时只先读第一句和问题;逐条问「这和要问的有关吗」;检查隐含前提。
- 错:还没理解就开始算。

**自己出题**
- 把已解决的问题改出新变体,检验自己是不是真的懂了。

## 方向

**一带百万**
- 在几个候选里选一个时,问「它会引出多少别的东西」,优先选根本性的那个。

**五层**
- 存在 → 交流 → 工具 → 方向(对准实际问题)→ 创新(被广泛采用)。给成果定位,问「下一层要做什么」。
- 书里自己承认这个分法不严格,当清单用。

## 检验(书里提到的)

- **删除法**:去掉某个因素后事情仍成立,它就不是本质。
- **反例法**:对每个特征问「有没有不具备它的 X」「有没有具备它却不是 X 的」。
- **新颖度逐级查**:先查自己知道的,再查团队、领域里有没有,自觉新不等于真新。
- **先生成后筛选**:生成和审查最好由不同的人(或不同的智能体)做;大量点子先聚类,再精炼成少数几个。
